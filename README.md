# BRent – Rental Management Platform

BRent is a modern full-stack rental management platform developed to simplify the process of renting and managing Houses, Shops, and Rooms.

The system is designed for both:

* Property owners who want to list and manage rental properties
* Users searching for rental properties easily and efficiently

## Main Features

* House, Shop, and Room Listings
* Property Management Dashboard
* Active & Pending Property Status Management
* Admin Analytics & Statistics Dashboard
* User Messaging & Query System
* Reviews & Feedback System
* Responsive Modern UI
* Secure Authentication & Role Management

## Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB
* Material UI (MUI)
* REST APIs
