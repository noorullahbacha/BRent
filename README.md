# BRent – Rental Management Platform

BRent is a modern full-stack rental management platform developed to simplify the process of renting and managing Houses, Shops, and Rooms.

The system is designed for both:

* Property owners who want to list and manage rental properties
* Users searching for rental properties easily and efficiently

## Main Features

* House, Shop, and Room Listings
* Property Management Dashboard
* Active & Pending Property Status Management
* Admin Analytics & Statistics Dashboard
* User Messaging & Query System
* Reviews & Feedback System
* Responsive Modern UI
* Secure Authentication & Role Management

## Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB
* Material UI (MUI)
* REST APIs

## Project Showcase

This repository is intended to showcase the functionality, UI/UX, and overall architecture of the BRent platform through screenshots and demo videos.

Due to project privacy and security considerations, the source code is not publicly available.

## Dashboard Modules

* Admin Dashboard
* Users Management
* Property Registration
* Houses Management
* Rooms Management
* Shops Management
* Reviews & Feedback
* Messaging System

This project was developed to strengthen practical skills in:

* Full Stack Web Development
